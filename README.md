# Claude Code Demo - 簡易計算機與天氣查詢

這是一個結合計算機功能與天氣資訊查詢的 Python 命令行工具。

## 功能特色

### 🧮 計算機功能
- **基本運算**: 加減乘除
- **進階運算**: 乘方、平方根、取餘數、絕對值、百分比
- **運算歷史**: 記錄並查看過往計算記錄
- **表達式計算**: 直接輸入數學表達式進行計算

### 🌤️ 天氣資訊
- **每日天氣查詢**: 查看指定城市的即時天氣
- **支援城市**: 台北、台中、台南、高雄
- **詳細資訊**: 溫度、體感溫度、濕度、風速、天氣狀況
- **雙模式運作**:
  - **模擬模式**: 無需 API 金鑰，使用模擬資料
  - **真實模式**: 設定 API 金鑰後，取得即時天氣資料

## 安裝與執行

### 基本使用（無需額外安裝）

```bash
python3 main.py
```

### 使用真實天氣資料（選用）

1. 前往 [OpenWeatherMap](https://openweathermap.org/api) 註冊並取得免費 API 金鑰

2. 設定環境變數:
```bash
export OPENWEATHER_API_KEY="your_api_key_here"
```

3. 安裝 requests 套件:
```bash
pip install requests
```

## 使用說明

### 計算機命令

```
基本運算:
  add <a> <b>      - 加法
  sub <a> <b>      - 減法
  mul <a> <b>      - 乘法
  div <a> <b>      - 除法

進階運算:
  pow <a> <b>      - 乘方
  sqrt <a>         - 平方根
  mod <a> <b>      - 取餘數
  abs <a>          - 絕對值
  pct <a>          - 百分比

直接輸入表達式:
  例: 2 + 3 * 4    - 直接計算數學表達式
```

### 天氣查詢命令

```
weather [城市]   - 查詢天氣 (預設:台北)
                   支援: 台北/台中/台南/高雄
```

### 其他命令

```
history          - 顯示運算歷史
clear            - 清除歷史記錄
last             - 顯示上次結果
help             - 顯示此說明
quit / exit      - 離開程式
```

## 技術細節

### 天氣模組架構
- **模組化設計**: 獨立的 `WeatherService` 類別
- **城市名稱轉換**: 支援中英文城市名稱
- **錯誤處理**: 完善的異常處理機制
- **格式化輸出**: 美觀的資訊呈現介面

### 安全性
- 表達式計算使用受限的 `eval`，僅允許基本數學運算
- 輸入驗證防止注入攻擊
